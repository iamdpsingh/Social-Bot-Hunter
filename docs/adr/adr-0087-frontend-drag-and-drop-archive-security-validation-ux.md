# ADR-0087: Frontend Drag-and-Drop Archive Security Validation UX

## Status
Accepted

## Context
Investigating analysts need immediate visual feedback on archive format detection, unpack progress, and rejection reasons.

## Decision
Provide `ArchiveUploadModal` with client-side file size guardrails, animated upload progress bar, format pill badges, and structured error banners.

## Consequences
Accessible (WCAG 2.1 AA), responsive upload experience integrated into the investigation workflow.
